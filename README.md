# S2AI · AI 学习树

> science to AI —— 一棵预制的 AI 学习树：**理论是树，项目是叶子**。理论地图（树干枝节）+ 叶子清单（项目叶子）互相挂靠，只做索引、顺序和取舍，不提供详细内容。设计对齐见 [DESIGN.md](./DESIGN.md)。

**在线访问**：<https://chenxiaoyu0505.github.io/S2AI/>

## 三种用法

1. **直接看**：静态网站，零成本，只读
2. **私有化**：clone 到本地、装进你的 Agent 作为插件——树开始生长（收集箱收新叶子、Agent 制作学习卡片）
3. **共建**：站长持续维护公共树干，私有树可随时同步 upstream

## 站点内容

| 板块 | 说明 |
| --- | --- |
| 理论地图（默认首页） | 树本身：12 篇章（枝干）· 69 模块 · 302 个学习点（枝节），星级 = 推荐学习 / 深入的程度，每篇章附「优先学习配方」；枝节下直接挂着长出来的叶子，点击直达项目官网 |
| 叶子清单 | 树上全部 97 片叶子（项目 + 练习项）：按枝干分组（树根组 → 各篇章 → 野生组），枝节索引标在每片叶子上（点击跳回理论地图），每片叶子带真实项目链接与一句话介绍，逐项勾选、进度本机保存 |
| 学习卡片 | 叶子的粗粒度介绍卡：挂在任意树上的节点（理论点 / 叶子 / 收集箱条目），一屏看完"这是什么、跟我什么关系、接下来去哪" |
| 收集箱 | 暂存区：新叶子（项目）与新枝节（论文 / 理论）两类收录（含野生枝节），附解析、下潜路径与观望/跟练/深入分级；学透的条目可"毕业"流转为学习卡片或直接长成叶子 |

首页 hero 内含「从哪开始」：零基础转行 / 有基础进阶两条入口路径。

> 个人化板块（项目拆解等）仅在学习树被私有化后出现（数据来自 `src/data/content.local.ts`，不进 git），公开站没有。
> 原「资源导航」已并入叶子清单：官网直达链接就是叶子的链接。

## 把这个仓库喂给你的 Agent

本树的内容都是数据文件（`src/data/*.ts`），没有写死的内容。**clone 下来丢给你的 Agent，让它读 `AGENTS.md`**，它就能帮你：

- 收录项目 / 论文到收集箱（自动解析、归类、概念提炼）
- 给叶子清单加新叶子（带树上落脚锚点）
- 制作 / 更新 / 剔除学习卡片
- 改造数据后自动构建验证、push 上线（Actions 自动部署）

你的个人内容（复盘、自己的拆解笔记、自己的叶子）写在 `src/data/content.local.ts` 即可——它已被 git 排除，只存在你自己的机器上，公开版本看不到。

```bash
git clone https://github.com/chenxiaoyu0505/S2AI.git my-tree
# 然后对你的 Agent 说：读 AGENTS.md，帮我把这棵学习树变成我自己的
```

## 技术栈

React 19 · TypeScript · Vite · Tailwind CSS · shadcn/ui

## 本地运行

```bash
npm install
npm run dev        # 开发预览
npm run build      # 类型检查 + 生产构建
```

## 数据同步（维护者向）

「理论地图」的数据不是手写的，由 `scripts/generate-theory.py` 从本地笔记的目录总览自动生成：

```bash
python scripts/generate-theory.py   # 更新笔记目录后重跑，再 commit 即可
```

树完整性校验（叶子锚点、卡片引用、收集箱归类等断链检查，CI 已接入）：

```bash
python scripts/check-tree.py
```

## 自动部署

push 到 `main` 后，GitHub Actions 自动执行构建并发布到 GitHub Pages（workflow 见 `.github/workflows/deploy.yml`），无需手动部署。

## 边界说明

- 本仓库为公开版：个人复盘、面试拆解等个人化内容**不在**其中（最多进 local 文件）
- 理论地图数据由维护者从本地笔记目录生成（`scripts/generate-theory.py`），笔记源文件不进本仓库——私有化克隆可直接使用生成好的 `src/data/theory.ts`，无需也无法重新生成
- 学习卡片（含模型卡）带 `date` 年月戳，模型迭代快，引用前留意时效
